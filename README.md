# 工作區知識圖譜（去識別化公開版）

這是一份以開源 [Graphify](https://github.com/Graphify-Labs/graphify) 建立的**主題層級**知識關聯圖，已做去識別化後公開。

## 這個頁面有什麼

- 研究、教學、商務合作與系統維運等**主題節點**與其群集
- 群集規模與連線結構（可搜尋、可點選）
- 互動圖使用 vis-network（CDN）在瀏覽器中繪製

## 這個頁面沒有什麼

公開版本**不包含**：

- 人名、職稱搭配的可識別身分
- 倫理審查案號、補助計畫代號、合約或金額
- 通訊軟體群組名稱或任何對話內容
- 原始檔名、內部資料夾路徑、電子郵件、電話
- 內部系統後台網址或權杖
- 精確的內部截止日與會議時段

若需要完整內部圖譜，請使用非公開的工作副本，不要使用本網站。
